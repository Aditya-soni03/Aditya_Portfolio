## 🚀 How to Run & Preview Locally

1. **Direct Browser Preview**:
   - Double-click `index.html` or open it with any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).
2. **Local Static Server**:
   - If you have Python installed:
     ```bash
     python -m http.server 8000
     ```
   - Then open `http://localhost:8000` in your browser.

## 🌐 Easy Deployment Options

This portfolio is 100% static and zero-dependency, making it free and instant to deploy:

### Option 1: GitHub Pages
1. Create a GitHub repository (e.g. `aditya-soni-portfolio`).
2. Push all files to the `main` branch.
3. In repository **Settings** → **Pages**, select `Deploy from a branch` → `main` branch → `/ (root)`.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

### Option 2: Vercel / Netlify
1. Drag and drop the `d:\suretrust` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on Vercel.
2. It deploys automatically with SSL in under 30 seconds!
